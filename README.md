# 🚗 OLA Rides Data Analysis (SQL & Python)

This project performs an **end-to-end Exploratory Data Analysis (EDA)** on **OLA ride booking data** using **SQL for querying & transformation** and **Python for analysis and visualization**.  
The objective is to uncover **ride trends, customer behavior, revenue drivers, and operational insights** to support data-driven decision-making.

This project reflects a **complete analytics workflow** and is well-suited for **Data Analyst, BI Analyst, MIS, and Product Analyst roles**.

---

## 🎯 Key Objectives

- Analyze overall **ride booking trends**
- Identify **peak demand periods**
- Understand **customer ride behavior**
- Evaluate **revenue patterns**
- Examine **cancellation trends**
- Generate **actionable business insights**

---

## 📦 Dataset Overview

The dataset contains structured ride-level information including:

- Booking ID & Customer ID  
- Ride Status (Completed / Cancelled)  
- Pickup & Drop Locations  
- Ride Distance & Duration  
- Fare Amount  
- Payment Method  
- Booking Date & Time  

---

## 🧠 Analysis Workflow

### 🔹 SQL Analysis
- Data filtering using `WHERE`
- Aggregations using `GROUP BY` and `HAVING`
- KPI calculations (rides, revenue, cancellations)
- Time-based trend analysis
- Business-focused query design

### 🔹 Python (EDA)
- Data cleaning and preprocessing using **Pandas**
- Exploratory analysis using **NumPy**
- Visual analysis using **Matplotlib & Seaborn**
- Pattern discovery across time and revenue metrics

## 📊 Key Insights

- Ride demand peaks during **office hours and weekends**
- **Short-distance rides** contribute the highest booking volume
- Certain pickup locations show **higher cancellation rates**
- Revenue concentration occurs during **peak time slots**
- **Digital payment methods** dominate completed rides

---

## 💡 Business Recommendations

### 1️⃣ Optimize Peak-Hour Operations
- Increase driver availability during high-demand periods
- Apply dynamic pricing to balance supply and demand

### 2️⃣ Reduce Ride Cancellations
- Improve driver allocation in high-cancellation zones
- Introduce incentives for confirmed bookings

### 3️⃣ Improve Customer Retention
- Target frequent riders with loyalty programs
- Personalize offers based on ride frequency and location

### 4️⃣ Enhance Revenue Strategy
- Promote long-distance rides with bundled discounts
- Optimize pricing based on demand patterns
